# HTML ↔ Markdown Cheat Sheet

## Headings

| HTML | Markdown |
|------|----------|
| `<h1>Heading 1</h1>` | `# Heading 1` |
| `<h2>Heading 2</h2>` | `## Heading 2` |
| `<h3>Heading 3</h3>` | `### Heading 3` |
| `<h4>Heading 4</h4>` | `#### Heading 4` |
| `<h5>Heading 5</h5>` | `##### Heading 5` |
| `<h6>Heading 6</h6>` | `###### Heading 6` |

---

## Paragraphs

### HTML

```html
<p>This is a paragraph of text.</p>
```

### Markdown

```md
This is a paragraph of text.
```

---

## Bold

### HTML

```html
<p>This is a <b>bold</b> word.</p>
```

### Markdown

```md
This is a **bold** word.
```

---

## Italics

### HTML

```html
<p>This is an <i>italic</i> word.</p>
```

### Markdown

```md
This is an _italic_ word.
```

> **Note:** `*italic*` also works in Markdown, but in this project use `_italic_`.

---

## Links

### HTML

```html
<a href="https://www.google.com">Google</a>
```

### Markdown

```md
[Google](https://www.google.com)
```

---

## Images

### HTML

```html
<img src="url/of/image.jpg" alt="Description of image" />
```

### Markdown

```md
![Description of image](url/of/image.jpg)
```

---

## Unordered Lists

### HTML

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

### Markdown

```md
- Item 1
- Item 2
- Item 3
```

> **Note:** `* Item` also works, but in this project use `- Item`.

---

## Ordered Lists

### HTML

```html
<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>
```

### Markdown

```md
1. Item 1
2. Item 2
3. Item 3
```

---

## Quotes

### HTML

```html
<blockquote>
  This is a quote.
</blockquote>
```

### Markdown

```md
> This is a quote.
```

---

### HTML


### Markdown
